## Projects

### 1. Age Calculator

A simple Python program that estimates a person's age based on their birth year.

**Features:**
- Accepts the user's birth year.
- Calculates their approximate age.
- Uses conditional statements to validate the birth year.
- Rejects birth years outside the accepted range.

**Concepts practised:**
- Variables and data types
- User input and type conversion
- Arithmetic operations
- Conditional statements (`if/else`)
- Comparison and logical operators
- F-strings

### 2. Wage Calculator

A Python program that calculates gross earnings based on hours worked and hourly pay, including overtime.

**Features:**
- Accepts hours worked and hourly pay.
- Calculates standard gross pay for up to 40 hours.
- Calculates overtime at 1.25 times the normal hourly rate.
- Rejects negative hours and hourly rates.
- Displays gross pay formatted to two decimal places.

**Concepts practised:**
- Variables and floating-point numbers
- User input
- Arithmetic operations
- Conditional statements (`if/elif/else`)
- Comparison and logical operators
- Formatted output using f-strings
